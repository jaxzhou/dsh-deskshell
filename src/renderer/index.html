缺少运行环境

需要 Node.js 运行时（含 npm）

dsh 依赖 Node.js 22 及以上版本与 npm。应用会自动下载官方发行版并配置到自己的数据目录， 无需管理员权限，也不会改动系统里已有的 Node.js； 之后 dsh 也安装在该目录内，与系统环境互不影响。

自动配置失败时的其他选择
  • 检查网络或代理：需要能访问 nodejs.org（或设置 DSH_D_NODE_MIRROR 指向镜像）。
  • 自行安装 Node.js 22+（nodejs.org），回到本窗口点击“重新检测”即可，应用会直接使用系统的 Node 与 npm。
  • 只需 dsh 运行时：nvm 用户可执行 nvm install --lts。
